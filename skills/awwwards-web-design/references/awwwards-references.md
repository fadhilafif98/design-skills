## How Phase 2 Uses This Catalog

2. **Select the single best match:** Select one reference from the catalog above that aligns with the business archetype.
3. **Decide directly (No user polling):** Formulate the single best design direction with its hero composition (`awwwards-patterns.md`), token strategy, and typography pairing.
4. **AI Visual Generation:** Generate all photography and visual assets directly using AI image generation (`image-generator`), preserving lighting and aesthetic coherence without fetching stock photos from the internet.
5. **Execute Full Pipeline:** Build with strict tokens, zero placeholder junk, live feature implementation, Chromium measurement gate (`inspect.sh` 0 FAIL), and independent subagent critique.
